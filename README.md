# Graftway

Graftway is being built to query build-system dependency graphs for build planning, CI, and developer tooling. Its initial focus is Bazel, with local queries and a Linux-hosted service.

## Documentation

Read the [documentation](https://ofek.github.io/graftway/), [contribution guide](docs/meta/contributing.md), [changelog](docs/meta/changelog.md), and [security policy](SECURITY.md).
