# Graftway

Graftway aims to make build-system dependency graphs useful for build planning, CI, and developer tooling. Its initial focus is Bazel, with local queries and a Linux-hosted service.

The project is in early development. See the [contribution guide](meta/contributing.md) to get involved and the [changelog](meta/changelog.md) for project updates.
