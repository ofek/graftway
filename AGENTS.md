# Repository instructions

See the [contribution guide](docs/meta/contributing.md) for development commands and documentation layout.

- Add Rust packages to the workspace in `Cargo.toml`. When adding the first package, commit `Cargo.lock` and connect the Rust mise tasks to the aggregate formatting, lint, test, and security tasks.
- Keep navigation in `zensical.toml` synchronized with the Markdown pages under `docs/`.
